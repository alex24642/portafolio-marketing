✏️ CÓMO EDITAR EL PORTAFOLIO
═══════════════════════════════════════════════════════════════════════════

1. EDITAR INFORMACIÓN PERSONAL
   • Abre index.html con un editor de texto (VS Code, Notepad++, etc.)
   • Busca: "INFORMACIÓN PERSONAL" (línea ~160)
   • Reemplaza los placeholders:
     - "— Nombre —" → Tu nombre completo
     - "— Materia —" → Nombre de la asignatura
     - "— editar aquí —" → Tus datos

2. CAMBIAR COLORES
   • Los colores están definidos en la sección <style>
   • Busca ":root {" para editar los colores principales:
     - --navy: Color de fondo oscuro
     - --gold: Color dorado principal
     - --cream: Color del texto

3. AGREGAR NUEVAS SECCIONES
   • Copia el bloque HTML de una sección
   • Pégalo debajo y modifica el ID (id="nueva-seccion")
   • Agrega un enlace en el menú <nav>

4. PERSONALIZAR CONTENIDO
   • Cada tarjeta tiene un <h3> (título) y <p> (párrafos)
   • Edita libremente el contenido entre las etiquetas
   • Mantén la estructura HTML igual
