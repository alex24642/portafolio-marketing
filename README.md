## 🚀 CÓMO USAR

### 1. ABRIR EL PORTAFOLIO
`
Abre: index.html (en tu navegador)
`
Se abrirá la página de inicio con 8 botones.

### 2. NAVEGAR POR SECCIONES
- **Usa los botones grandes** en la página de inicio
- **O usa el menú superior** en cada página
- **O haz clic en los enlaces** de las carpetas

### 3. ESTRUCTURA DE NAVEGACIÓN
`

## ✏️ EDITAR CONTENIDO

### Para cada página:
1. Abre el archivo .html con un editor (VS Code, Notepad++)
2. Busca el texto entre comillas — Editar aquí —
3. Reemplázalo con tu información
4. Guarda (Ctrl+S)
5. Recarga en el navegador (F5)

### Información a editar:
- **personal.html** - Datos personales, semestre, período
- **docente.html** - Nombre, asignatura, contacto
- **asignatura.html** - Objetivos, contenido temático
- Etc...

---

## 🎨 PERSONALIZACIÓN

### Cambiar Colores
Edita los colores al inicio de cada archivo HTML:
`css
:root {
  --navy: #0d1b2a;        /* Azul oscuro */
  --gold: #c9a84c;        /* Color dorado */
  --cream: #f5f0e8;       /* Color texto */
}
`

### Agregar Contenido
Cada página usa tarjetas (<div class="card">).
Puedes copiar y pegar para agregar más contenido.

## 📌 TIPS IMPORTANTES

1. **Mantén los archivos en la misma carpeta**
2. **No cambies los nombres de los archivos** (o actualiza todos los enlaces)
3. **Coloca tus archivos en las carpetas correspondientes**
4. **Recarga con F5** después de editar HTML
5. **Usa un editor de código** (VS Code es lo mejor)
